# KrishiRaksha360

KrishiRaksha360 is a community service project that promotes the safe and responsible use of fertilizers and pesticides among farmers in Satuluru Village.

## Development

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

The optional Express/PostgreSQL server can be started with:

```bash
npm run server
```

Copy `.env.example` to `.env` and provide local PostgreSQL settings before starting the server. Never commit `.env`.

## Production build

```bash
npm run build
```
